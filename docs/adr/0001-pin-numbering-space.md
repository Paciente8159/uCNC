# Pin numbering space freeze and reserved expansion range

The canonical `DIO` pin numbering table (friendly pin names → numbers, documented in `src/hal/mcus/README.md`) is frozen at `1..215` for compatibility across every boardmap, mcumap, the IO HAL and the mcumap generator; `216..254` is reserved for future official expansion (mainly communications or special applications), and negative values belong exclusively to the IO-HAL extender mechanism (`DIO<n> < 0` = extended pin). Extending the table is a cross-cutting change (mcumaps, `io_hal.h`, README table, generator) and must go through this ADR. `.claude/skills/ucnc-hal-mcu/scripts/check_mcu_pin_contract.py` enforces the canonical table, generic IO HAL coverage (including peripheral chip-select pins), mcumap mappings, and non-use of the reserved range in CI.
