# Tiered peripheral access policy (bare-metal first)

Backends access hardware through the thinnest abstraction the platform provides, chosen bare-metal first: direct register writes where feasible (AVR, STM32, SAMD21), vendor SDK drivers where the hardware requires them (timer alarms, WiFi, USB stacks), and Arduino/RTOS cores only behind explicit opt-in flags (`USE_ARDUINO_*_LIBRARY`, `ARDUINO_ARCH_*`, `TARGET_*`). Each backend documents its access tier in its README. This preserves the compile-time performance and small binaries of the register-based backends while keeping framework-dependent ports (RP2040 with Arduino-Pico, the ESP32 family with ESP-IDF, LPC176X Arduino glue) first-class; previously the spec asserted "direct register writes only", which contradicted those ports.
